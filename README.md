# PokeTeams

<!-- CI badge goes here (Phase 1) -->

PokeTeams is a small Blazor Web App (.NET 10, Interactive Server) for building a team of up to six Gen-1 Pokémon from [PokeAPI](https://pokeapi.co/) and seeing the team's stat totals, type coverage and weakest stat. The app is deliberately simple: it exists as a vehicle for practising GitHub Actions for the GH-200 exam (see `LAB-GH200.md`). Run it with `dotnet run --project src/PokeTeams.Web`; `/healthz` returns `ok`.
